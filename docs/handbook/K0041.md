# K0041. Brownian motion in a planar wedge of any angle: exact survival probability

**Area:** Diffusion to a target. **Kind:** exact (exact within the stated model).

A Brownian particle in a wedge of opening angle alpha with absorbing edges survives up to time t with a probability that depends only on y = r0^2/(8Dt) and the starting angle. For any alpha it is a finite sum of error functions plus one integral; at long times it decays as t^(-pi/(2 alpha)).

## Model

$$ \partial_tP=D\Delta P,\ P|_{\varphi=0}=P|_{\varphi=\alpha}=0,\ \text{start at }(r_0,\varphi_0) $$

## Result

$$ S=\mathrm{erf}(\sqrt{2y}\sin\min(\varphi_0,\tfrac\pi2))+\sum_{j=1}^{k+1}(-1)^j[\mathrm{erf}(\sqrt{2y}\sin\min(j\alpha+\varphi_0,\tfrac\pi2))-\mathrm{erf}(\sqrt{2y}\sin\min(j\alpha-\varphi_0,\tfrac\pi2))]+I(y,\varphi_0),\ y=\frac{r_0^2}{8Dt} $$

## Use it

```python
from kramers.formulas import wedge_survival
wedge_survival(t: 'float', r0: 'float', phi0: 'float', alpha: 'float', D: 'float' = 1.0) -> 'float'
```

```text
Probability that a Brownian particle started at polar position (r0, phi0) inside the wedge 0 < phi < alpha
has not touched either edge by time t (both edges absorbing; any 0 < alpha < 2 pi).

Eq. (27): with y = r0^2/(8 D t) and k = floor(pi/(2 alpha) - 1/2),
S = erf(sqrt(2y) sin(min(phi0, pi/2))) + sum_{j=1}^{k+1} (-1)^j [erf(sqrt(2y) sin(min(j alpha + phi0, pi/2)))
    - erf(sqrt(2y) sin(min(j alpha - phi0, pi/2)))] + an integral term. <x^2> = 2 D t per coordinate.
```

| Parameter | Meaning |
|---|---|
| `t` | time |
| `r0` | start distance from the apex |
| `phi0` | start angle, 0 < phi0 < alpha |
| `alpha` | opening angle of the wedge, 0 < alpha < 2 pi |
| `D` | diffusion coefficient (<x^2> = 2Dt per coordinate) |

## When it holds

Free two-dimensional diffusion, both edges of the wedge absorbing, any opening angle below 2 pi. Exact.
