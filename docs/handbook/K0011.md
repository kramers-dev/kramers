# K0011. Variance of the passage time through a noisy saddle-node, any bias and thresholds

**Area:** Neuron models. **Kind:** exact (exact within the stated model).

The variance of the interspike interval of the quadratic integrate-and-fire neuron with white noise, for any bias and any reset and threshold, is a triple integral of exp(+-V/D) (Lindner, Longtin and Bulsara, Eq. A.4). Together with the mean it gives the coefficient of variation across the whole firing range.

## Model

$$ \dot x = \beta + x^2 + \sqrt{2D}\,\xi(t),\ \text{reset } x_-,\ \text{threshold } x_+,\ V=-x^3/3-\beta x $$

## Result

$$ \langle\Delta T^2\rangle=\frac{2}{D^2}\int_{-\infty}^{x_+}dz\,e^{V(z)/D}\left[\int_{-\infty}^{z}dy\,e^{-V(y)/D}\right]^2\int_{z}^{x_+}dx\,\Theta(x-x_-)\,e^{V(x)/D} $$

## Use it

```python
from kramers.formulas import saddle_node_passage_variance
saddle_node_passage_variance(beta: 'float', D: 'float', x_minus: 'float' = -inf, x_plus: 'float' = inf) -> 'float'
```

```text
Variance of the time from reset x_minus to threshold x_plus for dx/dt = beta + x^2 + sqrt(2D) xi.

This is the quantity of Lindner, Longtin and Bulsara's Eq. (A.4) (and of Eq. (3.2)
for infinite thresholds, whose printed prefactor must be doubled; see the notes).
Computed with the quadrature solver's moment recursion.
```

| Parameter | Meaning |
|---|---|
| `beta` | bias |
| `D` | noise intensity |
| `x_minus` | reset (default -inf) |
| `x_plus` | threshold (default +inf) |

  - Read: author's PDF (journal typesetting), pages read 12 and 14 Oct 2026.
  - As printed: $ \langle\Delta T^2\rangle=\frac{2}{D^2}\int_{-\infty}^{x_+}dz\,e^{V(z)/D}\left[\int_{-\infty}^{z}dy\,e^{-V(y)/D}\right]^2\times\int_{z}^{x_+}dx\,\Theta(x-x_-)\,e^{V(x)/D} $
  - Notation: same symbols; V(x) = -x^3/3 - beta x (their Eq. 2.6).

## When it holds

White noise, any bias, any thresholds (infinite ones included). Exact.

## Notes

Questions for the authors (Lindner, Longtin and Bulsara), both from computations. (1) Eq. (3.2) as printed has the prefactor (9/D)^(2/3); with it, Eq. (3.2) gives exactly half of the paper's own Eq. (3.5) at beta = 0 (computed ratio 2.0000 at beta = 0, -0.5 and 0.8), and with 2 (9/D)^(2/3) the two agree. (2) In Eq. (A.3) as printed the middle integrand is exp(-V(z)/D); for a linear potential V = -mu x that gives 8.3e3 instead of the exact 2 D L / mu^3 = 0.728 (mu = 1.3, D = 0.4, L = 2), while exp(+V(z)/D) reproduces it. Eqs. (A.1), (A.2) and (A.4) are consistent with each other and with this entry. We read both as misprints but may have misread the notation.
