# K0006. Escape rate near a saddle-node, weak noise (Kramers limit)

**Area:** Escape over a barrier. **Kind:** asymptotic (leading term of an expansion; its error is mapped against an exact reference).

Below the saddle-node bifurcation (beta < 0) and for weak noise, the rate of passage for dx/dt = beta + x^2 + sqrt(2D) xi is sqrt|beta|/pi times exp(-4|beta|^(3/2)/(3D)): Kramers' formula for the cubic potential. It is too high by 5/(18 B) to leading order with the barrier B = 4|beta|^(3/2)/(3D); the check maps it against the exact rate.

## Model

$$ \dot x = \beta + x^2 + \sqrt{2D}\,\xi(t),\ \beta<0,\ x_\pm=\pm\infty $$

## Result

$$ r \simeq \frac{\sqrt{|\beta|}}{\pi}\exp\!\left[-\frac{4|\beta|^{3/2}}{3D}\right],\quad D\ll|\beta|^{3/2} $$

## Use it

```python
from kramers.formulas import saddle_node_kramers_rate
saddle_node_kramers_rate(beta: 'ArrayLike', D: 'float') -> 'np.ndarray | float'
```

```text
Rate sqrt|beta|/pi * exp(-4|beta|^(3/2)/(3D)) for dx/dt = beta + x^2 + sqrt(2D) xi, beta < 0.

Warns (``ValidityWarning``) when the barrier 4|beta|^(3/2)/(3D) is below 10, and
says how far the formula is from the exact rate there.
```

| Parameter | Meaning |
|---|---|
| `beta` | bias (negative: below the bifurcation) |
| `D` | noise intensity |

## When it holds

Weak noise: barrier B = 4|beta|^(3/2)/(3D) large. The formula is too high by 5/(18 B) + O(1/B^2) (computed check against K0004): 7.8% at B = 5, 3.2% at B = 10, 1.2% at B = 25, 0.57% at B = 50.
