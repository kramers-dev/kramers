# K0024. Distribution of the switching point under a ramp (quasi-static approximation)

**Area:** Driven escape and switching under a ramp. **Kind:** exact (exact within the stated model).

When a control (a force, a current, a field) is ramped and the system escapes with the rate k(F) of the frozen value F, the switching value has density k(F)/Fdot exp(-integral of k/Fdot). This turns any rate law into switching-current, rupture-force or switching-field histograms, and is exact for a rate process; the rate picture itself fails for ramps that are fast compared with relaxation in the well.

## Model

$$ \dot S(t)=-k(F(t))\,S(t),\quad \dot F = \dot F(F) > 0 $$

## Result

$$ p(F)=\frac{k(F)}{\dot F(F)}\exp\!\left(-\int_{F_0}^{F}\frac{k(F')}{\dot F(F')}\,dF'\right) $$

## Use it

```python
from kramers.formulas import switching_distribution
switching_distribution(rate: 'Callable[[np.ndarray], np.ndarray]', loading_rate: 'float | Callable[[np.ndarray], np.ndarray]', F_max: 'float', F0: 'float' = 0.0, n: 'int' = 25, partial: 'bool' = False) -> 'SwitchingDistribution'
```

```text
Distribution of the control value F at which the system switches while F rises from F0.

p(F) = k(F) / Fdot(F) * exp(-integral from F0 to F of k / Fdot), the quasi-static
survival law (Dudko, Hummer and Szabo, Eq. 2; Kurkijarvi; Garg). ``rate`` is k(F)
(vectorised, positive); ``loading_rate`` is dF/dt, a number or a function of F.
The integral is accumulated in logarithms on Chebyshev panels, so rates spanning
hundreds of orders of magnitude are handled.

``F_max`` must lie beyond essentially all switching (survival below 1e-12 there);
otherwise this raises, unless ``partial=True``, when the mean and variance are those
of the switching points below ``F_max`` and ``mass`` says how much probability that is.
```

| Parameter | Meaning |
|---|---|
| `rate` | k(F) |
| `loading_rate` | dF/dt (number or function of F) |
| `F_max` | upper end of the grid |
| `F0` | starting value |
| `n` | Chebyshev order per panel |

## When it holds

Exact for a process with the frozen rate k(F). The frozen-rate picture needs the ramp to be slow compared with relaxation in the well; for the ramped noisy fold its error is mapped in K0030.
