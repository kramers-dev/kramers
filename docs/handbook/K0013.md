# K0013. First-passage duality: conditional exit times do not depend on the sign of the drift

**Area:** Diffusion to a target. **Kind:** exact (exact within the stated model).

For drift-diffusion between two absorbing points, the distribution of the exit time conditioned on leaving through a given end is the same for drift v and -v, from any starting point. From the midpoint, the conditional distributions at the two ends are therefore identical, although the exit probabilities differ. The function gives the conditional mean at the origin as printed by Krapivsky and Redner.

## Model

$$ dX = v\,dt + \sqrt{2D}\,dW,\quad 0<X<L,\ \text{both ends absorbing} $$

## Result

$$ T(\ell)=\frac{\ell}{v}\frac{e^{-vL/D}+e^{-v\ell/D}}{e^{-v\ell/D}-e^{-vL/D}}-\frac{2L}{v}\frac{1-e^{-v\ell/D}}{1-e^{-vL/D}}\frac{e^{-vL/D}}{e^{-v\ell/D}-e^{-vL/D}} $$

## Use it

```python
from kramers.formulas import conditional_time_to_origin
conditional_time_to_origin(ell: 'float', L: 'float', v: 'float', D: 'float') -> 'float'
```

```text
Mean time to hit 0 before L from ell, given that 0 is hit first (Krapivsky and Redner, Eq. 28b).

v > 0 is drift away from the origin; the value is the same for v and -v. The printed
form cancels catastrophically when |v| L / D is very small or large, so the value is
computed from the equivalent form of K0012 (through z coth z - 1), which is accurate
for every v, including v = 0; a check compares the two where both are accurate.
```

| Parameter | Meaning |
|---|---|
| `ell` | start |
| `L` | length |
| `v` | drift away from the origin |
| `D` | diffusion coefficient |

## When it holds

Constant drift and diffusion. The drift-sign invariance holds for any start; the equality of the two ends holds only for a start at the midpoint.
