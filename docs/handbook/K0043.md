# K0043. Run-and-tumble particle in a harmonic trap, absorbed at the centre: survival transform and decay exponent

**Area:** Active and anomalous motion. **Kind:** exact (exact within the stated model).

A run-and-tumble particle in a harmonic trap, dx/dt = -mu x + v0 sigma(t), absorbed when it reaches the trap centre, has a survival probability whose Laplace transform is a ratio of Gauss hypergeometric functions. At late times it decays as exp(-theta t), where theta solves a hypergeometric equation and lies between the reversal rate (slow reversals) and mu (fast reversals, the passive limit).

## Model

$$ \dot x=-\mu x+v_0\sigma(t),\ \sigma=\pm1\ \text{reversing at rate}\ \gamma,\ 0<x_0<v_0/\mu,\ \text{absorbed at}\ x=0 $$

## Result

$$ \tilde Q_-(x_0,s)=\frac1s\left[1-\frac{F\left(\frac s\mu,\frac{s+2\gamma}\mu,\frac{s+\gamma}\mu,\frac12(1-\frac{\mu x_0}{v_0})\right)}{F\left(\frac s\mu,\frac{s+2\gamma}\mu,\frac{s+\gamma}\mu,\frac12\right)}\right],\quad F\left(-\tfrac\theta\mu,\tfrac{2\gamma-\theta}\mu,\tfrac{\gamma-\theta}\mu,\tfrac12\right)=0 $$


```text
Laplace transform Q~(x0, s) = int_0^inf e^{-st} Q(x0, t) dt of the survival probability of a run-and-tumble
particle dx/dt = -mu x + v0 sigma(t) (sigma = +-1 reversing at rate gamma), absorbed at the trap centre x = 0.

initial = "towards" (the paper's -v0), Eq. (84):
    Q~- = (1/s) [1 - F(s/mu, (s+2g)/mu, (s+g)/mu, z) / F(s/mu, (s+2g)/mu, (s+g)/mu, 1/2)],  z = (1 - mu x0/v0)/2;
initial = "away" (+v0), from Eqs. (82), (83) and (67):
    Q~+ = 1/s - (g/s) F(s/mu, (s+2g)/mu, (s+g+mu)/mu, z) / D(s, g, mu).
F is the Gauss hypergeometric function. Requires 0 < x0 < v0/mu (inside the region the particle can reach).
E[e^{-sT}] = 1 - s Q~(s).
```

| Parameter | Meaning |
|---|---|
| `s` | Laplace variable |
| `x0` | start position, 0 < x0 < v0/mu |
| `v0` | self-propulsion speed |
| `mu` | trap stiffness over friction (relaxation rate) |
| `gamma` | reversal rate |
| `initial` | 'towards' (the paper's -v0) or 'away' (+v0) from the centre |

- **Primary source:** A. Dhar, A. Kundu, S. N. Majumdar, S. Sabhapandit and G. Schehr, Phys. Rev. E 99, 032132 (2019). [doi:10.1103/PhysRevE.99.032132](https://doi.org/10.1103/PhysRevE.99.032132)

  - Read: arXiv:1811.03808v2 PDF p. 12 as a page image and the TeX source, opened 22 Nov 2026 (two readers); v2 was revised in June 2022, after publication; journal text not checked.
  - As printed: $ \tilde{Q}_- (x_0,s) =\frac{1}{s} \left[1- \frac{F\left( \frac{s}{\mu}, \frac{s+2\gamma}{\mu}, \frac{s+\gamma}{\mu},\frac{1}{2}(1-\frac{\mu x_0}{v_0})\right)}{F\left( \frac{s}{\mu}, \frac{s+2\gamma}{\mu}, \frac{s+\gamma}{\mu},\frac{1}{2} \right)}\right];\ \tilde{q}_+(z,s)= -\frac{\gamma}{s} \frac{F\left( \frac{s}{\mu}, \frac{s+2\gamma}{\mu}, \frac{s+\gamma+\mu}{\mu},z \right)}{\mathcal{D}(s,\gamma,\mu)} $
  - Notation: same symbols; F = 2F1; gamma is the reversal rate. For a start away from the centre this entry uses Eqs. (82) and (67), Q~+ = 1/s - (gamma/s) F/D. Eq. (85) as printed in arXiv v2, (gamma/s)[1 - F/D], diverges as s -> 0 for gamma != 1 (a finite mean needs a finite limit) and misses the simulation; read as a question for the authors until the journal version is checked.

## When it holds

One dimension, harmonic trap, constant self-propulsion speed with Poissonian reversals, no translational diffusion, absorbing wall at the trap centre, start inside the reachable region 0 < x0 < v0/mu. Exact.
