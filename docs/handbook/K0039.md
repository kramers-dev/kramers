# K0039. Symmetric Levy flight: mean exit time from an interval

**Area:** Active and anomalous motion. **Kind:** exact (exact within the stated model).

A symmetric alpha-stable Levy flight started at x0 leaves the interval (-L, L) after a mean time (L^2 - x0^2)^(alpha/2) / (Gamma(1 + alpha) sigma0^alpha). At alpha = 2 this is the Brownian result (L^2 - x0^2)/(2D); for alpha < 2 the flight can leave by jumping over an end.

## Model

$$ \dot x=\zeta_\alpha(t),\ \langle e^{ik\,\Delta x}\rangle=e^{-\sigma_0^\alpha|k|^\alpha\Delta t},\ \tau=\min\{t:|x(t)|\ge L\} $$

## Result

$$ \langle\tau(x_0)\rangle=\frac{(L^2-x_0^2)^{\alpha/2}}{\Gamma(1+\alpha)\,\sigma_0^{\alpha}} $$

## Use it

```python
from kramers.formulas import levy_flight_exit_time
levy_flight_exit_time(x0: 'float', L: 'float', alpha: 'float', sigma0: 'float' = 1.0) -> 'float'
```

```text
Mean time for a symmetric alpha-stable Levy flight started at x0 to leave the interval (-L, L).

<tau(x0)> = (L^2 - x0^2)^(alpha/2) / (Gamma(1 + alpha) sigma0^alpha)   (0 < alpha <= 2).
The increments over a time dt have the characteristic function exp(-sigma0^alpha |k|^alpha dt), so
at alpha = 2 the motion is Brownian with D = sigma0^2 (<x^2> = 2 D t). Leaving means landing
anywhere outside the interval: a jump over an end counts.
```

| Parameter | Meaning |
|---|---|
| `x0` | start, -L < x0 < L |
| `L` | half-width of the interval |
| `alpha` | stability index, 0 < alpha <= 2 |
| `sigma0` | scale: increments have characteristic function exp(-sigma0^alpha |k|^alpha dt) |

## When it holds

Symmetric alpha-stable Levy flight (no finite speed), 0 < alpha <= 2, the whole exterior of the interval absorbing. Exact. Not a Levy walk, and not the local condition p(-L) = p(L) = 0 of older work.
