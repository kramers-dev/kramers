# K0025. Escape rates from a switching histogram (Fulton-Dunkleberger transformation)

**Area:** Driven escape and switching under a ramp. **Kind:** estimator (turns measured data into a quantity of the model).

Counts of switching events in bins of the ramped control (current, force, field) give the escape rate at each bin from the logarithm of the ratio of survivors before and after the bin. Assigned to bin centres it is accurate to second order in the bin width; the standard error from counting statistics is added here.

## Model

$$ \dot S = -\Gamma(I)\,S,\ I \text{ ramped at constant } |\dot I| $$

## Result

$$ \Gamma(I_k)=\frac{|\dot I|}{\Delta I}\ln\!\left(\frac{\sum_{j\ge k}P_j}{\sum_{j\ge k+1}P_j}\right) $$

## Use it

```python
from kramers.formulas import histogram_to_rate
histogram_to_rate(counts: 'ArrayLike', edges: 'ArrayLike', ramp_rate: 'float') -> 'RateEstimate'
```

```text
Escape rate at each bin centre from switching counts under a linear ramp.

Gamma(I_k) = |dI/dt| / Delta I_k * ln( sum_{j >= k} n_j / sum_{j >= k+1} n_j )
(Kaemmerer et al. Eq. 13, after Fulton and Dunkleberger), assigned to bin centres,
where it is second order in the bin width. ``stderr`` is the delta-method standard
error from binomial counting, |dI/dt| / Delta I_k * sqrt(n_k / (N_k N_{k+1})), a
computed addition, not in the source. Bins with no later switches give NaN.
```

| Parameter | Meaning |
|---|---|
| `counts` | switching events per bin |
| `edges` | bin edges (increasing) |
| `ramp_rate` | dI/dt |

## When it holds

A single switching event per ramp, constant ramp rate, rate process (quasi-static). Bin centres: second order in the bin width (relative errors 1.9e-2, 4.9e-3, 1.2e-3 at widths 2, 1, 0.5 kT/x, from a research agent's numerics); bin edges: first order.
