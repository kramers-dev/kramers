# K0032. Diffusion with resetting in an interval: mean exit time through either end

**Area:** Stochastic resetting. **Kind:** exact (exact within the stated model).

A Brownian particle in an interval with two absorbing ends, reset to its start x0 at rate r, leaves after a mean time [sinh((b-a)alpha0)/(sinh((b-x0)alpha0)+sinh((x0-a)alpha0)) - 1]/r. Unlike the half-line, the mean is finite without resetting, so resetting can raise it or lower it.

## Model

$$ \partial_t Q_r = D\,\partial_x^2 Q_r - r\,Q_r + r\,Q_r(x_0,t),\ Q_r(a,t)=Q_r(b,t)=0 $$

## Result

$$ \langle T_r(x_0)\rangle=\frac{1}{r}\left[\frac{\sinh((b-a)\alpha_0)}{\sinh((b-x_0)\alpha_0)+\sinh((x_0-a)\alpha_0)}-1\right],\quad \alpha_0=\sqrt{r/D} $$

## Use it

```python
from kramers.formulas import resetting_interval_mean_time
resetting_interval_mean_time(x0: 'float', a: 'float', b: 'float', r: 'float', D: 'float') -> 'float'
```

```text
Mean time to leave (a, b) through either end, starting at and resetting to x0 at rate r.

T = [ sinh((b-a) alpha0) / (sinh((b-x0) alpha0) + sinh((x0-a) alpha0)) - 1 ] / r, alpha0 = sqrt(r/D).
Evaluated through sinh(u+v) - sinh u - sinh v = 4 sinh(u/2) sinh(v/2) sinh((u+v)/2), so that there is no
cancellation as r -> 0 and no overflow for large r.
```

| Parameter | Meaning |
|---|---|
| `x0` | start and reset position |
| `a` | left absorbing end |
| `b` | right absorbing end |
| `r` | resetting rate |
| `D` | diffusion coefficient (<x^2> = 2Dt between resets) |

## When it holds

One dimension, free diffusion, Poissonian instantaneous resetting to the start, both ends absorbing. Exact.
