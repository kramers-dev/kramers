# K0012. Drift-diffusion on an interval: exit probability, mean and conditional exit times

**Area:** Diffusion to a target. **Kind:** exact (exact within the stated model).

For Brownian motion with drift v and diffusion D started at x in (0, L) with both ends absorbing: the probability of leaving through L, the mean exit time, and the mean exit time conditioned on each end, in closed form, including the zero-drift limits.

## Model

$$ dX = v\,dt + \sqrt{2D}\,dW,\quad 0<X<L,\ \text{both ends absorbing} $$

## Result

$$ \pi_L=\frac{1-e^{-vx/D}}{1-e^{-vL/D}},\ T_L=\frac{1}{v}\left[L\coth\frac{vL}{2D}-x\coth\frac{vx}{2D}\right],\ T_0=T_L|_{x\to L-x},\ T=\pi_LT_L+(1-\pi_L)T_0 $$

## Use it

```python
from kramers.formulas import drift_diffusion_interval
drift_diffusion_interval(x: 'float', L: 'float', v: 'float', D: 'float') -> 'IntervalExit'
```

```text
Exit statistics of dX = v dt + sqrt(2D) dW from x in (0, L), both ends absorbing.

p_right is Redner's Eq. (4.12). The conditional means are Srivastava et al.'s
Eqs. (11)-(12) moved to [0, L] (thresholds +-zeta = +-L/2 around the midpoint):
T_L = [L coth(vL/2D) - x coth(vx/2D)] / v and T_0 the same with x -> L - x.
Evaluated through h(z) = coth z - 1/z, so that small drifts lose no digits and
large ones do not overflow.
```

| Parameter | Meaning |
|---|---|
| `x` | start |
| `L` | length |
| `v` | drift (towards L if positive) |
| `D` | diffusion coefficient |

## When it holds

Constant drift and diffusion, both ends absorbing, start inside. Exact.
