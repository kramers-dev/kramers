# K0010. Firing rate of the leaky integrate-and-fire neuron with white noise (Siegert formula)

**Area:** Neuron models. **Kind:** exact (exact within the stated model).

The stationary firing rate of the leaky integrate-and-fire neuron with white-noise input is the reciprocal of the refractory period plus the mean first-passage time of an Ornstein-Uhlenbeck process from reset to threshold, written as one integral of exp(u^2)(1 + erf u).

## Model

$$ \tau\dot V = -V + \mu + \sigma\sqrt{\tau}\,\eta(t),\ V=\theta \to \text{spike, reset to } V_r $$

## Result

$$ \frac{1}{\nu}=\tau_{rp}+\tau\sqrt{\pi}\int_{(V_r-\mu)/\sigma}^{(\theta-\mu)/\sigma}du\,e^{u^2}\left(1+\operatorname{erf}u\right) $$

```python
from kramers.formulas import lif_firing_rate
lif_firing_rate(mu: 'float', sigma: 'float', theta: 'float', V_r: 'float', tau: 'float', tau_rp: 'float' = 0.0) -> 'float'
```

```text
Stationary rate of tau dV/dt = -V + mu + sigma sqrt(tau) eta(t), threshold theta, reset V_r.

Brunel's Eq. (21): 1/nu = tau_rp + tau sqrt(pi) * integral from (V_r - mu)/sigma to
(theta - mu)/sigma of exp(u^2) (1 + erf u) du.

Note the convention: the free membrane potential has standard deviation
sigma / sqrt(2). Pass ``sigma = sqrt(2) * sd`` if you hold the standard deviation.
```

| Parameter | Meaning |
|---|---|
| `mu` | mean input |
| `sigma` | noise amplitude (free SD is sigma/sqrt 2) |
| `theta` | threshold |
| `V_r` | reset |
| `tau` | membrane time constant |
| `tau_rp` | refractory period |

## When it holds

Diffusion approximation of the input (white noise); stationary state. Exact for that model. Threshold at most 26 sigma above the mean input.
