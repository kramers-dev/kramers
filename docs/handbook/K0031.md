# K0031. Diffusion with resetting in d dimensions: mean time to reach an absorbing sphere

**Area:** Stochastic resetting. **Kind:** exact (exact within the stated model).

A particle diffusing in d dimensions and reset to its start at rate r reaches an absorbing sphere of radius a, from distance R, after a finite mean time given by a ratio of modified Bessel functions of order |1 - d/2|. In d = 1 it is the one-dimensional resetting result; in d >= 2 it diverges as a -> 0.

## Model

$$ \partial_t q = D\nabla^2 q - r\,q + r\,\delta(\mathbf{x}-\mathbf{X}_r),\ \text{absorbing on } |\mathbf{x}|=a,\ |\mathbf{X}_r|=R $$

## Result

$$ T=\frac{1}{r}\left[\left(\frac{a}{R}\right)^{\nu}\frac{K_{|\nu|}(\alpha_0a)}{K_{|\nu|}(\alpha_0R)}-1\right],\quad \nu=1-\frac{d}{2},\ \alpha_0=\sqrt{r/D} $$

## Use it

```python
from kramers.formulas import resetting_sphere_mean_time
resetting_sphere_mean_time(R: 'float', a: 'float', r: 'float', D: 'float', d: 'int') -> 'float'
```

```text
Mean time to reach the sphere |x| = a from distance R > a, resetting to the start at rate r, in d dimensions.

T = [ (a/R)^nu K_|nu|(alpha0 a) / K_|nu|(alpha0 R) - 1 ] / r, with nu = 1 - d/2 and alpha0 = sqrt(r/D).
Evaluated in logarithms with exponentially scaled Bessel functions, so it holds for large alpha0 R.
```

| Parameter | Meaning |
|---|---|
| `R` | distance of the start and reset point from the centre |
| `a` | radius of the absorbing sphere |
| `r` | resetting rate |
| `D` | diffusion coefficient (<x_i^2> = 2Dt) |
| `d` | dimension |

## When it holds

Free diffusion in d dimensions, Poissonian instantaneous resetting to the starting point, perfectly absorbing sphere. Exact. In d >= 2 the target must have a > 0.
