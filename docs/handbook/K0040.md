# K0040. Search with resetting and a return home at constant speed: mean time to the target

**Area:** Stochastic resetting. **Kind:** exact (exact within the stated model).

A searcher diffuses from home towards a target at distance L, gives up at rate r and walks home at speed v before searching again. The mean time is the search term of instantaneous resetting, (e^z - 1)/r, plus a return term (L/v)[2 sinh(z)/z - 1], z = L sqrt(r/D); the optimal rate falls as returns get slower.

## Model

$$ \text{diffusion from } x=0 \text{ to an absorbing target at } L;\ \text{at rate } r\text{, return to } 0 \text{ at speed } v_r \text{ (time } |x|/v_r\text{), blind to the target} $$

## Result

$$ \langle T_r\rangle=\frac{1}{r}\left(e^{\sqrt{\tau_d r}}-1\right)+\tau_b\left[\frac{2\sinh\sqrt{\tau_d r}}{\sqrt{\tau_d r}}-1\right],\quad \tau_d=\frac{L^2}{D},\ \tau_b=\frac{L}{v_r} $$

## Use it

```python
from kramers.formulas import home_return_mean_time
home_return_mean_time(L: 'float', D: 'float', v_return: 'float', r: 'float') -> 'float'
```

```text
Mean time for a searcher diffusing from home (x = 0) to find a target at distance L, when it gives up at
rate r and walks back home at speed v_return (blind to the target on the way), then searches again.

<T_r> = (e^z - 1)/r + (L/v_return) [2 sinh(z)/z - 1],  z = sqrt(r L^2 / D)   (Eqs. 9-10).
The first term is the search (entry K0015); the second is the time spent walking home. <x^2> = 2 D t.
```

| Parameter | Meaning |
|---|---|
| `L` | distance from home to the target |
| `D` | diffusion coefficient (<x^2> = 2Dt) |
| `v_return` | speed of the walk home |
| `r` | rate of giving up and returning |

## When it holds

One dimension, free diffusion from home to an absorbing target, Poissonian giving-up, a ballistic return at constant speed that cannot find the target, no waiting at home. Exact.
