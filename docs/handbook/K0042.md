# K0042. Run-and-tumble particle on a half-line: exact first-passage density to the origin

**Area:** Active and anomalous motion. **Kind:** exact (exact within the stated model).

A particle that moves at speed v and reverses direction at rate gamma, started at x > 0, first reaches the origin with a density given by modified Bessel functions of sqrt(t^2 - x^2) (in units 1/gamma and v/gamma). If it starts towards the origin it arrives at t = x/v without reversing with probability e^(-gamma x/v); at long times the density decays as t^(-3/2), like Brownian motion.

## Model

$$ \dot x=v\,\sigma(t),\ \sigma=\pm1\ \text{reversing at rate}\ \gamma,\ x(0)=x>0,\ \text{absorbing at}\ 0 $$

## Result

$$ f_+=\frac{e^{-\tau}}{\tau+\xi}\left[\xi I_0(\sqrt{\tau^2-\xi^2})+\sqrt{\tfrac{\tau-\xi}{\tau+\xi}}I_1(\sqrt{\tau^2-\xi^2})\right],\ f_-=e^{-\tau}\frac{\xi}{\sqrt{\tau^2-\xi^2}}I_1(\sqrt{\tau^2-\xi^2})+e^{-\tau}\delta(\tau-\xi) $$

## Use it

```python
from kramers.formulas import rtp_first_passage_density
rtp_first_passage_density(t: 'float', x: 'float', v: 'float', gamma: 'float', initial: 'str' = 'towards') -> 'float'
```

```text
Density of the time at which a run-and-tumble particle started at x > 0 first reaches the origin.

dx/dt = v sigma(t), sigma = +-1 reversing at rate gamma, no translational diffusion. In units tau = gamma t,
xi = gamma x / v (Eq. 35):
  initial velocity away from the origin ("away", the paper's +v):
    f+ = e^-tau / (tau + xi) [xi I0(sqrt(tau^2 - xi^2)) + sqrt((tau - xi)/(tau + xi)) I1(sqrt(tau^2 - xi^2))] for tau > xi
  initial velocity towards the origin ("towards", the paper's -v):
    f- = e^-tau xi / sqrt(tau^2 - xi^2) I1(sqrt(tau^2 - xi^2)) for tau > xi, plus an atom e^-xi at tau = xi
    (arrival without any reversal), which is not included in the returned density.
The returned value is per unit time (the factor gamma is included). The density is zero for t < x/v.
```

| Parameter | Meaning |
|---|---|
| `t` | time |
| `x` | start distance from the origin |
| `v` | speed |
| `gamma` | reversal rate (the velocity flips sign at this rate) |
| `initial` | 'towards' (the paper's -v) or 'away' (+v) from the origin |

## When it holds

One dimension, speed v, Poissonian reversals, no translational diffusion, the origin absorbing. Exact.
